# 🏯 40 — Perguruan Pengendali Api Iblis Jiuyou (九幽魔火武阁)

> **Kategori:** Lembaga Pendidikan Spesialis Manipulasi Api Ekstrem & Penempaan Magma
> **Lokasi:** Sayap Luar Benteng Besi Api Neraka, Wilayah Jiuyou Zhou
> **Kepala Instruktur:** Panglima Tempur Yan Kuang (Ranah Fashen Jing)

---

## 1. Disiplin Latihan & Pengendalian Mental

Perguruan ini mendidik para kultivator api untuk mengendalikan suhu tinggi ekstrem dari lelehan magma Jiuyou. Berbeda dari anggapan orang luar yang mengira kultivator iblis bertindak tanpa kendali akal, siswa di perguruan ini justru dilatih menguasai emosi mereka dengan disiplin besi.

Kemarahan liar adalah penyebab utama kultivator api iblis terbakar sendiri (*self-immolation*). Di akademi ini, siswa diajarkan bernapas tenang di tengah panas membara 1.500 derajat Celsius dan memfokuskan bara api murni pada ujung tombak atau telapak tangan.

---

## 2. Fasilitas Pelatihan

1. **Jembatan Rantai Besi di Atas Kawah Lava:** Tempat melatih keseimbangan fisik dan meditasi di tengah semburan gas belerang panas.
2. **Kamar Pemadaman Api Batin:** Ruang pendinginan dengan formasi es spirit untuk menstabilkan suhu tubuh siswa setelah latihan intensif.
3. **Panggung Adu Tembak Bola Api Hitam:** Uji ketepatan sasaran dan efisiensi konsumsi Qi saat melepaskan jurus proyektil api.
