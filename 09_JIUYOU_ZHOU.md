# 🔥 09 — Jiuyou Zhou (九幽州 — Wilayah Jurang Api Sembilan Neraka)

> **Status Geopolitik:** Wilayah Inti Faksi Demonic (Mo Dao — Klan Asura & Penguasa Api Hitam)
> **Ciri Khas Ekologis:** Kaldera Lava Hitam Mendidih, Puncak Bebatuan Obsidian Tajam, Nyala Api Neraka Jiuyou
> **Ibu Kota Wilayah:** Kota Benteng Besi Api Neraka (Youhuo Tiecheng - 幽火铁城)

---

## 1. Lore & Karakteristik Wilayah

Jiuyou Zhou adalah wilayah jurang vulkanik raksasa di selatan benua, tempat retakan bumi terdalam memancarkan magma berhawa api iblis murni (*Jiuyou Hellfire*). Wilayah ini dikuasai oleh **Istana Asura Jiuyou (Jiuyou Asura Palace)**, pilar utama kaum Demonic.

Masyarakat Demonic di Jiuyou Zhou memuja disiplin militer yang sangat keras, keberanian tanpa gentar, dan supremasi kekuatan. Namun mereka bukanlah bandit tanpa akal; mereka tunduk pada **Hukum Besi Asura (Iron Asura Code)**. Setiap perselisihan diselesaikan di arena duel darah resmi (*Life-and-Death Ring*). Pengkhianatan terhadap sumpah saudara diancam hukuman dibakar hidup-hidup di kawah api obsidian.

---

## 2. Lokasi Utama (Points of Interest)

### 1. Kota Benteng Besi Api Neraka (Youhuo Tiecheng)
- Benteng raksasa berdinding batu obsidian dan lelehan logam meteorit gelap yang berdiri kokoh di atas jembatan magma raksasa.
- Tempat bertahtanya Raja Asura Api dan Dewan Panglima Perang Demonic.

### 2. Kawah Sembilan Tingkat Jiuyou (Nine-Layer Jiuyou Caldera)
- Jurang kawah bertingkat sembilan menuju inti api magma bumi. Semakin dalam tingkatannya, semakin dahsyat suhu panas dan tekanan Qi Api yang dialami tubuh.

### 3. Lembah Meteor Hitam Penempa Besi (Black Meteor Forging Valley)
- Lokasi di mana pandai besi Demonic memanfaatkan api neraka alami untuk menempa senjata berat berbahan dasar besi darah purba dan tulang naga api.

### 4. Perguruan Pengendali Api Iblis Jiuyou (Jiuyou Demonic Flame Academy)
- Akademi tempur yang melatih kultivator cara mengendalikan amarah batin menjadi kobaran api iblis hitam tanpa terbakar gila (*Qi Deviation*).

## 3. Sub-Tempat Baru & Lore Tambahan

### 5. Perkampungan Penambang Bebas Batu Hitam (Heiyan Zhai - 黑岩寨)
- **Kategori:** Pemukiman / Desa Penambang Merdeka & Sanxiu Api
- **Geografi & Lingkungan:** Terletak di teras tebing basal hitam di atas jurang magma dangkal. Rumah-rumah dipahat langsung dari gua batu bara api dan terlindung oleh tirai asap belerang dingin.
- **Lore & Sejarah:** Didirikan oleh mantan budak tambang dan kultivator liar yang telah memperoleh kemerdekaan mereka melalui pertarungan duel berdarah di arena Asura. Di desa ini berlaku hukum kehormatan para pekerja: siapapun yang memeras penambang lemah atau mencuri hasil galian orang lain akan dilempar ke sungai lahar.
- **Dinamika Faksi:** Berada di bawah pengawasan longgar garnisun Asura. Menjadi pemasok utama batu bara hitam spirit dan belerang murni bagi para alkemis dan pandai besi lintas faksi.
- **Rumor & Plot Hook:** Para penambang menemukan urat bijih baru di celah terdalam yang memancarkan nyala api biru dingin; beberapa penambang yang menyentuhnya pingsan dengan meridian membeku di tengah hawa panas.
- **Sumber Daya / Bahaya:** *Batu Bara Hitam Berapi Abadi*, *Belerang Kristal Jiwa*; Bahaya semburan geiser gas belerang beracun dan longsoran batu obsidian.

### 6. Kota Pos Garnisun Bara Merah (Chiyan Guan - 赤焰关)
- **Kategori:** Kota Satelit / Benteng Pertahanan Perbatasan Demonic
- **Geografi & Lingkungan:** Benteng pertahanan terdepan berdinding lempengan besi meteorit merah setinggi empat puluh meter yang memotong jalan sempit antara Jiuyou Zhou dan Zhongzhou. Dilengkapi meriam api formasi raksasa yang ditenagai magma langsung dari bawah tanah.
- **Lore & Sejarah:** Dibangun sebagai benteng pengawas untuk menegakkan kepatuhan terhadap Perjanjian Tiga Batas. Pos ini menyaring setiap kultivator luar yang ingin memasuki wilayah api neraka serta memastikan prajurit Demonic tidak melintasi batas netral bersenjata lengkap tanpa izin dewan.
- **Dinamika Faksi:** Dijaga oleh Legiun Garda Besi Asura berpakaian zirah hitam pekat. Meskipun garang, mereka sangat menjunjung tinggi hukum gencatan senjata dan tidak pernah mengganggu pedagang yang membawa token paspor kekaisaran resmi.
- **Rumor & Plot Hook:** Tertangkap seorang penyusup dari Sekte Pedang Tianxu yang menyamar menjadi pedagang kristal; dokumen rahasia yang dibawanya menyiratkan adanya konspirasi pihak ketiga yang ingin memicu perang antara faksi Ortodoks dan Demonic.
- **Sumber Daya / Bahaya:** *Pelat Besi Tempa Chiyan*, *Minyak Api Penyala Obor Roh*; Disiplin militer tanpa toleransi; membawa senjata terhunus tanpa izin di depan gerbang akan langsung ditembak formasi api.

### 7. Celah Lembah Magma Belerang Asura (Xiuluo Huogu - 修罗火谷)
- **Kategori:** Area Liar / Celah Jurang Sungai Lahar Aktif
- **Geografi & Lingkungan:** Lembah ngarai terbelah di mana dasarnya mengalir sungai lahar pijar bersuhu ribuan derajat. Uap belerang kuning membumbung tinggi membentuk awan panas beracun yang menutupi langit ngarai.
- **Lore & Sejarah:** Medan pembuktian diri bagi para pendekar muda Demonic. Sebelum diakui sebagai kesatria Asura sejati, seorang murid harus menyeberangi ngarai ini hanya dengan melompati bongkahan batu obsidian yang hanyut di atas aliran lahar panas tanpa menggunakan pedang terbang.
- **Dinamika Faksi:** Terbuka bagi siapapun yang ingin melatih ketahanan tubuh terhadap api atau mencari bahan pembakar pil tingkat tinggi.
- **Rumor & Plot Hook:** Di tengah ngarai terdapat pusaran lahar di mana bunga "Teratai Api Sembilan Kelopak" dikabarkan mekar setiap tiga ratus tahun sekali; waktu mekarnya diperkirakan tinggal beberapa hari lagi.
- **Sumber Daya / Bahaya:** *Batu Obsidian Mengapung*, *Kristal Belerang Asura*; Bahaya terpeleset ke dalam lahar mendidih dan serangan Salamander Magma Raksasa berkaki delapan.

### 8. Hutan Karang Obsidian Hitam Tajam (Heiyao Fenglin - 黑曜峰林)
- **Kategori:** Area Liar / Hutan Pilar Kaca Vulkanik Tajam
- **Geografi & Lingkungan:** Gugusan pilar-pilar batu obsidian hitam mengkilap setinggi puluhan meter yang memiliki tepi setajam silet. Sinar matahari yang membias di permukaan pilar menciptakan pantulan cahaya gelap yang menyilaukan.
- **Lore & Sejarah:** Terbentuk dari pendinginan mendadak semburan magma purba akibat benturan teknik es tingkat dewa puluhan ribu tahun lampau. Lingkungan tajam ini menjadi sarang alami monster berkulit keras dan tempat para praktisi pedang demonic melatih ketajaman tebasan mereka.
- **Dinamika Faksi:** Wilayah berbahaya tak bertuan; sering menjadi tempat duel maut rahasia antar pendekar yang ingin menuntaskan dendam tanpa campur tangan hukum sekte.
- **Rumor & Plot Hook:** Suara gemerincing tajam sering terdengar dari tengah hutan karang di saat badai malam; konon ada seekor Kalajengking Zirah Obsidian Kuno yang tengah melepaskan kulit cangkang lamanya.
- **Sumber Daya / Bahaya:** *Pecahan Kaca Obsidian Murni*, *Batu Asah Hitam Pemotong Baja*; Bahaya tergores pilar batu tajam yang dapat merobek pakaian pelindung spiritual biasa.

### 9. Reruntuhan Altar Penjinak Api Purba (Yuhuo Yizhi - 御火遗址)
- **Kategori:** Reruntuhan Kuno / Kompleks Kuil Pengendali Magma Kuno
- **Geografi & Lingkungan:** Kuil batu basal setengah hancur yang dibangun di atas pulau karang di tengah danau lahar mati. Sembilan pilar penyangga kuil diukir dengan simbol pemujaan api primordial dan roda kendali magma purba yang macet.
- **Lore & Sejarah:** Tempat para leluhur klan Asura pertama kali menemukan cara menjinakkan hawa api iblis Jiuyou tanpa kehilangan akal sehat. Sebelum altar ini hancur dalam perang kuno, kuil ini berfungsi mengatur aliran tekanan magma di seluruh penjuru selatan benua.
- **Dinamika Faksi:** Tempat keramat yang dihormati para tetua ranah tinggi Istana Asura. Hanya mereka yang berhati teguh dan tahan panas yang mampu bertahan berdiri di atas pelataran kuil.
- **Rumor & Plot Hook:** Di bawah lantai altar terdapat rongga penyimpanan api di mana "Inti Percikan Api Jiuyou Purba" masih tersisa; menyerap percikan ini konon dapat memperkuat api kultivasi secara eksponensial.
- **Sumber Daya / Bahaya:** *Batu Prasasti Teknik Penjinak Api*, *Abu Bara Primordial*; Bahaya ledakan formasi api kuno yang masih aktif secara sporadis.

### 10. Gua Kawah Tulang Iblis Primordial (Mogu Dongxue - 魔骨洞穴)
- **Kategori:** Reruntuhan Kuno / Gua Fosil Monster Purba
- **Geografi & Lingkungan:** Rongga kawah bawah tanah yang sangat luas di mana langit-langit guanya terbentuk dari tulang punggung raksasa monster jurang zaman purba. Dinding gua ditumbuhi lumut api merah yang menyala dalam kegelapan.
- **Lore & Sejarah:** Makam alamiah bagi binatang iblis purba yang tewas tertimbun lelehan lahar saat bencana pembentukan dunia. Udara di dalam gua sarat dengan hawa kemarahan kuno dan energi intisari tulang yang sangat kuat, sering digunakan untuk menumbuhkan kekuatan fisik para penempa raga.
- **Dinamika Faksi:** Lokasi latihan eksklusif bagi prajurit terpilih kaum Demonic; pengelana luar dilarang masuk tanpa persetujuan dari Panglima Istana Asura.
- **Rumor & Plot Hook:** Di ujung terdalam gua, terdengar suara dengkuran berat yang menggetarkan stalaktit batu bara; para murid senior berbisik bahwa salah satu tulang monster purba tersebut sedang mengalami proses regenerasi kehidupan secara gaib.
- **Sumber Daya / Bahaya:** *Serbuk Tulang Iblis Purba*, *Lumut Api Menyala (Glow Flame Moss)*; Bahaya tekanan mental dari hawa amarah monster purba yang dapat memicu kegilaan (*Blood Frenzy*).

## 4. Sumber Daya Khas & Ekologi Spiritual

- **Bahan Khas:** *Kristal Api Neraka Hitam (Black Hellfire Crystal)*, *Batu Obsidian Darah*, *Sisik Salamander Magma Purba*, *Belerang Api Jiuyou*, *Batu Bara Hitam Berapi Abadi*, *Batu Obsidian Mengapung*.
- **Bahaya Lingkungan:** *Gelombang Hawa Panas Magma (Magma Heat Surge)* — menyebabkan status dehidrasi cepat dan kelelahan stamina ganda bagi mereka yang tidak memiliki ketahanan elemen api.
