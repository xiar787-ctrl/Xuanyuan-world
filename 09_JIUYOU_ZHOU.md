## 1. Lore, Sejarah Purba & Mitos Regional Lengkap

Jiuyou Zhou adalah wilayah jurang vulkanik raksasa di selatan Benua Xuanyuan, tempat retakan bumi terdalam memancarkan magma berhawa api iblis murni (*Jiuyou Hellfire*). Wilayah ini dikuasai oleh **Istana Asura Jiuyou (Jiuyou Asura Palace)**, pilar utama kaum Demonic (Mo Dao).

Masyarakat Demonic di Jiuyou Zhou memuja disiplin militer yang sangat keras, keberanian tanpa gentar, dan supremasi kekuatan. Namun mereka bukanlah bandit liar tanpa akal; mereka tunduk pada **Hukum Besi Asura (Iron Asura Code)**. Setiap perselisihan diselesaikan di arena duel darah resmi (*Life-and-Death Ring*). Pengkhianatan terhadap sumpah saudara diancam hukuman dibakar hidup-hidup di kawah api obsidian, dan menindas kaum fana tanpa senjata dianggap sebagai tindakan memalukan yang merusak martabat ksatria iblis.

### Bencana Letusan Kawah Tingkat Sembilan Tiga Ribu Tahun Lalu
Tiga ribu tahun silam, tekanan magma dari inti naga api bumi meluap tak terkendali dan menembus sembilan lapisan batuan dasar, memicu semburan lahar hitam yang hampir menenggelamkan separuh wilayah selatan benua. Raja Asura generasi ketiga memimpin seratus panglima perangnya mengorbankan separuh kultivasi mereka untuk menancapkan Sembilan Belati Besi Meteorit ke dalam kawah inti, menstabilkan letusan dan membentuk **Kawah Sembilan Tingkat Jiuyou**.

### Penempaan Besi Hitam & Api Penguji Hati
Di Jiuyou Zhou, api iblis tidak dipandang sebagai instrumen penghancur membabi buta, melainkan sarana pembersih kelemahan jiwa. Para pandai besi Demonic memanfaatkan suhu ekstrem api neraka untuk melebur bijih meteorit gelap menjadi senjata-senjata pusaka legendaris berbobot ribuan kati yang ditakuti musuh di medan perang.
