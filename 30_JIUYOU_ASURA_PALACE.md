# 🩸 30 — Istana Asura Jiuyou (九幽修罗宫 — Jiuyou Asura Palace)

> **Afiliasi Faksi:** Demonic (Mo Dao — Penguasa Api Hitam & Disiplin Besi Asura)
> **Markas Pusat:** Benteng Besi Api Neraka, Wilayah Jiuyou Zhou
> **Kaisar Asura Api (Asura Sovereign):** Raja Iblis Yan Jueshen (Ranah Tianjun Jing Tingkat Puncak)

---

## 1. Doktrin Kekuatan Mutlak & Hukum Kehormatan Besi

Istana Asura Jiuyou mewakili kekuatan faksi Demonic yang paling tertata dan disegani. Mereka memegang teguh keyakinan bahwa alam semesta ini pada hakikatnya kejam dan hanya kekuatan absolut yang mampu menjamin keadilan sejati.

Namun, berbeda dari bandit liar tak bertuan, pengikut Istana Asura terikat pada **Kode Kehormatan Asura (Asura Iron Code)**:
- Tantangan pertarungan hanya sah jika disepakati secara terbuka di panggung duel (*Life-and-Death Ring*). Menusuk dari belakang atau meracuni air minum kota dilarang keras dan dicap sebagai tindakan pengecut yang pantas dihukum mati.
- Sumpah darah (*Blood Oath*) yang ditandatangani dengan api neraka tidak boleh dilanggar oleh pangeran maupun prajurit biasa.
- Mereka menghormati musuh yang bertarung berani hingga tetes darah penghabisan dan memperlakukan jasad ksatria dengan penghormatan api kremasi suci.

---

## 2. Struktur Militer Demonic

1. **Legiun Kavaleri Badai Obsidian:** Pasukan berkuda lapis baja hitam yang mengendarai monster serigala api magma.
2. **Aula Penempaan Senjata Neraka:** Pusat perakitan tombak darah dan pedang bergerigi penyerap hawa panas.
3. **Kubah Meditasi Inti Magma Sembilan Tingkat:** Ruang bertapa bawah tanah tempat para jenderal menyerap panas bumi murni ke dalam urat meridian mereka.

---

## 3. Syarat Penerimaan Murid & Warisan Seni

- **Persyaratan:** Memiliki Akar Spiritual Api Jiuyou atau Petir Gelap, keberanian menatap maut tanpa berkedip, dan kesetiaan mutlak pada panji Asura.
- **Teknik Utama Istana:** *Kitab Pembakar Surga Api Neraka Asura (Asura Hellfire Heaven-Incinerating Scripture)* — Tier 8 (Mengubah Qi tubuh menjadi kobaran api hitam yang melahap pertahanan lawan dan tidak dapat dipadamkan oleh air biasa).
